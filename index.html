Antes de cargar, detente

Control previo obligatorio

NO

No subas datos personales, calificaciones, historiales disciplinarios ni información institucional sensible.

  • Trabaja con documentos públicos, autorizados, anonimizados o ficticios.
  • Aplica las políticas internas de CECAR antes que cualquier capacidad técnica.
  • Si dudas sobre el nivel de sensibilidad, no cargues el archivo.

La protección de Workspace no reemplaza las políticas internas ni la autorización para usar cada documento.

¿Cómo funciona un cuaderno?

Un proyecto documental independiente

1Fuentes

El corpus autorizado: documentos, enlaces, audio, video y datos.

2Chat

Pregunta o encarga acciones. Selecciona qué fuentes participan y abre las citas.

3Studio

Transforma el corpus en informes, audio, video, mapas, tablas y presentaciones.

Cada cuaderno es independiente: Gemini Notebook no consulta varios cuadernos al mismo tiempo.

Construye un insumo real

Práctica guiada

  1. Elige un documento público, autorizado o ficticio.
  2. Crea un cuaderno con un nombre y una etiqueta clara.
  3. Haz una pregunta que responda una necesidad de tu dependencia.
  4. Abre al menos una cita y contrasta el contexto.
  5. Genera un formato reutilizable: correo, FAQ, guía o tabla.
CRITERIO DE ÉXITOPuedo explicar de dónde salió cada afirmación.

Cinco verbos para construir mejores prompts

Hoja de trucos

  1. ContextualizaQuién eres y qué proceso atiendes
  2. DelimitaQué fuentes y qué alcance debe respetar
  3. EncargaQué tarea concreta debe realizar
  4. FormateaCómo necesitas recibir el resultado
  5. Exige evidenciaCitas, páginas y vacíos no resueltos

Contexto + fuentes + tarea + formato + evidencia
